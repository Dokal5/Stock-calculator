# Product Spec (v1)

## Objective
Single-ticker decision-support web app that produces transparent fair value ranges and timing-aware buy zone guidance.

## Output contract
1. Current price
2. Bear/base/bull fair value range
3. Premium/discount to base fair value
4. Buy zone (Strong buy, Normal buy, Watchlist, Avoid chasing)
5. Final decision score out of 100
6. Timing state
7. Key risk flags
8. Plain language reasoning

## Non-goals
- Broker execution
- Portfolio optimization
- Fully automated recommendations
